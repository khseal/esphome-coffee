# Кофеварка и кофемолка на Sonoff Dual R3

ESPHome-конфиг для Sonoff Dual R3 v1 (ESP32, CSE7761). Кофеварка включается вместе с устройством. Кофемолка запускается кнопкой и останавливается по таймеру или по набранному весу.

Вес берётся либо с Gaggiuino по HTTP, либо с весов Futula Kitchen Scale 3 по Bluetooth. Целевая доза читается из профиля Gaggiuino (`recipe.coffeeIn`).

## Поведение

- Реле кофеварки включено после старта. Отдельных кнопок кофеварки нет. Если три часа ничего не происходит, кофеварка выключается. Помол и нажатие кнопки кофемолки сбрасывают этот таймер.
- Кнопка на корпусе и кнопка **Grinder Button** в Home Assistant делают одно и то же. Первое нажатие запускает помол, второе останавливает.
- Переключатель **Grinder** только подаёт питание на реле и сам помол по весу не ведёт.
- Пока включена кофеварка и включён **Gaggiuino Scale** или **Futula Scale**, помол идёт по весу. Иначе кофемолка работает по таймеру **Grind Time** (шаг 0,1 с).
- Остановка по весу считает прирост от веса в момент старта, тара в ноль не обязательна.
- **Grind Target Override** больше нуля заменяет дозу профиля и для Gaggiuino, и для Futula.
- **Grind Stop Early** выключает мотор раньше цели: после реле зёрна ещё падают в чашку.
- Пока кофеварка выключена, профиль Gaggiuino не запрашивается. Весы Futula при этом могут оставаться подключёнными.
- Если Futula была включена до перезагрузки, контроллер продолжает искать весы, пока переключатель включён.
- Энергия считается по обоим каналам CSE7761 за сутки и за месяц. На Dual R3 v1 знак мощности перевёрнут шунтом, в конфиге он умножается на −1.

## Железо

| Что | Куда |
| --- | --- |
| CSE7761 UART | GPIO25 TX, GPIO26 RX, 38400 8E1 |
| Реле кофеварки | GPIO27 |
| Реле кофемолки | GPIO14 |
| Кнопка кофемолки | GPIO33, подтяжка к питанию |
| Светодиод | GPIO13, инвертирован |

Плата именно v1 с CSE7761, не v2 с BL0939. Логгер по UART выключен: этот порт занят микросхемой энергии.

Futula использует BLE. Пока к весам подключён Dual R3, телефон одновременно подключиться не может. MAC весов и IP Gaggiuino задаются в начале `coffee.yaml`.

## Секреты

Wi-Fi, пароль веб-интерфейса и ключ API в репозиторий не входят. Рядом с конфигом нужен `secrets.yaml`:

```yaml
wifi_ssid: "..."
wifi_password: "..."
web_server_username: "..."
web_server_password: "..."
api_encryption_key: "..."
```

## Прошивка

Конфиг собран под ESPHome 2026.10 и аддон ESPHome в Home Assistant. У Dual R3 нет удобного USB. Если устройство раньше работало на Tasmota с таблицей разделов safeboot, первая запись ESPHome делается по OTA с миграцией разделов. В конфиге уже стоит `allow_partition_access: true`.
