# Кофеварка и кофемолка на Sonoff Dual R3

ESPHome-конфиг для Sonoff Dual R3 v1 (ESP32, CSE7761). Кофеварка включается вместе с устройством. Кофемолка запускается кнопкой и останавливается по таймеру или по набранному весу.

Вес берётся либо с Gaggiuino по HTTP, либо с весов Timemore Black Mirror Dot по Bluetooth. Целевая доза читается из профиля Gaggiuino (`recipe.coffeeIn`). Пока Timemore подключены, Dual R3 отдаёт их вес в Gaggiuino, притворяясь весами Decent Scale.

## Поведение

- Реле кофеварки включено после старта. Отдельных кнопок кофеварки нет. Если три часа ничего не происходит, кофеварка выключается. Помол и нажатие кнопки кофемолки сбрасывают этот таймер.
- Кнопка на корпусе и кнопка **Grinder Button** в Home Assistant делают одно и то же. Первое нажатие запускает помол, второе останавливает. Реле кофемолки в Home Assistant скрыто, чтобы ассистент не включил мотор напрямую.
- Пока включена кофеварка и включён **Gaggiuino Scale** или **Timemore Scale**, помол идёт по весу. Иначе кофемолка работает по таймеру **Grind Time** (шаг 0,1 с).
- Остановка по весу считает прирост от веса в момент старта. **Grind Auto Tare** (по умолчанию выключено) перед помолом обнуляет Timemore и ждёт, пока вес сядет около нуля. Если ноль не получился, мотор не запускается. Кнопка **Scale Tare** делает то же обнуление без помола. Чашка уже должна стоять на весах. Gaggiuino обнулить по API нельзя.
- **Grind Target Override** больше нуля заменяет дозу профиля.
- **Grind Stop Early** — на сколько граммов мотор выключается раньше цели, потому что зёрна ещё падают после реле. Во время помола берётся поток, г/с: у Timemore свой, из кадра веса, а если его нет — запасной расчёт по весу на контроллере. Запас равен потоку, умноженному на упреждение в секундах. Через 2,5 с после остановки фактический вес сравнивается с целью: перелёт увеличивает упреждение, недобор уменьшает. Чашку в эти секунды не снимают. Значение в Home Assistant можно поправить вручную. Поток, упреждение и ошибка видны как **Grind Flow**, **Grind Lead** и **Grind Error**.
- Пока кофеварка выключена, профиль Gaggiuino не запрашивается. Весы Timemore при этом могут оставаться подключёнными.
- Энергия считается по обоим каналам CSE7761 за сутки и за месяц. На Dual R3 v1 знак мощности перевёрнут шунтом, в конфиге он умножается на −1.

## Весы Timemore

Весы ищутся по имени `TIMEMORE_Dot`, MAC в конфиге не задаётся. Контроллер сопрягается с ними без PIN-кода, как приложение Timemore, и держит одно соединение: приложение на телефоне должно быть закрыто.

- **Timemore Scale** включает поиск и подключение. Выключение переключателя сразу рвёт связь.
- Если связь оборвалась сама, повторное подключение начнётся через 12 с.
- После сброса весов старый ключ не подходит. Кнопка **Timemore Unpair** забывает сохранённые ключи, следующее подключение сопрягает весы заново.
- Если переключатель был включён до перезагрузки, контроллер продолжает искать весы.
- **Timemore Connected** показывает, что связь установлена.
- Для пролива Dual R3 объявляет себя по Bluetooth как `Decent Scale` и пересылает туда каждый кадр веса Timemore. В Gaggiuino включают Bluetooth-весы и выбирают эти весы. Команда тары с Gaggiuino обнуляет Timemore. Пока Timemore не подключены, Gaggiuino может соединиться, но вес обновляться не будет.

IP Gaggiuino задаётся в начале `coffee.yaml`. Веб-интерфейса у контроллера нет: управление идёт через Home Assistant. Если Wi-Fi пропадёт, поднимется резервная точка доступа.

## Железо

| Что | Куда |
| --- | --- |
| CSE7761 UART | GPIO25 TX, GPIO26 RX, 38400 8E1 |
| Реле кофеварки | GPIO27 |
| Реле кофемолки | GPIO14 |
| Кнопка кофемолки | GPIO33, подтяжка к питанию |
| Светодиод | GPIO13, инвертирован |

Плата именно v1 с CSE7761, не v2 с BL0939. Логгер по UART выключен: этот порт занят микросхемой энергии.

## Секреты

Wi-Fi, пароль резервной точки доступа и ключ API в репозиторий не входят. Рядом с конфигом нужен `secrets.yaml`:

```yaml
wifi_ssid: "..."
wifi_password: "..."
web_server_password: "..."
api_encryption_key: "..."
```

## Прошивка

Конфиг собран под ESPHome 2026.10 и аддон ESPHome в Home Assistant. У Dual R3 нет удобного USB. Если устройство раньше работало на Tasmota с таблицей разделов safeboot, первая запись ESPHome делается по OTA с миграцией разделов. В конфиге уже стоит `allow_partition_access: true`.
